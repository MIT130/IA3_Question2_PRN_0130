# IA-3 Question 2 – Personalized Hash Table

**PRN:** 202501100130  
**Seed S:** 130  
**Scenario:** Cold-drink flavours (`PRN mod 3 = 0`)  
**Hash method:** Division method, `h(key) = key mod m` (PRN even)  
**Collision handling:** Linear probing (PRN mod 2 = 0)  
**Dataset:** `30, 43, 56, 69, 82, 95, 8, 21, 34, 47, 60, 73, 86, 99, 12, 25, 38, 51, 64, 77`

Formula: `v[i] = (S + 13*i) mod 100`, for `i=0...19`.

**Table size:** `m=23` is an implementation choice. Question 2 gives `key mod m` but does not prescribe a table size. This program uses a prime table size greater than the 20 input values. If your instructor specifies another m, change `TABLE_SIZE` and redo the trace.

```bash
g++ -std=c++11 -Wall -Wextra main.cpp -o hash_table
./hash_table
```
Windows MinGW:
```bash
g++ -std=c++11 -Wall -Wextra main.cpp -o hash_table.exe
hash_table.exe
```
`sample_output.txt` contains the output generated by compiling and running the supplied source.

## Algorithm
1. Initialize every slot to -1 (empty).
2. Compute home index using `key % 23`.
3. If occupied, inspect the next slot: `(index + 1) % 23`.
4. Insert in the first empty slot.
5. Display all table positions.
